# 当前玩法与设计

版本 0.5.2，整理日期 2026-10-07。动态判定线重做已回退，当前为稀疏长光线方案。

## 交互与画面

全舞台点击统一随机发声，鼠标、触摸和键盘共用半拍队列。同格取最新，避免连点堆积；没有音符判定、分数或位置选音。设置面板事件不进入舞台。窗口尺寸变化、失焦和切回后台同样清理尚未播出的半拍队列，避免复播旧声音或卡音。

单张正常动漫比例坐姿人物居中，自动缩放幅度约 0.45%，点击短促跳动约 1.4%。背景由 HTML/CSS 和 Canvas 生成，主色深墨蓝，有雨雾；点击有多种光环、粒子和线条，加强人物周边呼吸光与背景反馈。

长光线偶尔跨越画面，方向和跨度随机，桌面至多两条、手机至多一条，保留空档。几何和呼吸光读取音频时钟，保持低动效设置可用。

## 音频

音乐约 84.069 秒，89.992 BPM。网格锚点 0.60061 秒、小节相位 1，半拍为最小吸附单位。首次完整第一拍约 2.600788 秒。循环约 0.60061–83.274625 秒，共 31 个四拍小节；接缝仍需真人确认。

25 条语音以 rate=1 播放。FFmpeg 裁去开头空白/低声底噪，保留最多约 6 ms 起音余量并提前补偿。18 条有裁切，最长约 257 ms。派生双声道 24 位 FLAC 避免再次有损编码，不声称与原 MP4 字节一致。

调度采用 25 ms 防迟到余量、75 ms 提前窗口；最多四个活动语音，抢占淡出。音乐源增益约 0.92，语音响起时伴奏避让约 -2.5 dB，输出含压缩和软峰值保护。混音修改必须测量实际输出。

设置带版本和校验，读写失败仍可游玩；按音乐源哈希和校准修订号识别旧拍点，保留合法音量，用户手动校准可保存。
